# ホテルニューイタヤ デジタルサイネージCMS 試作

## 概要

50インチ縦型モニターでの表示を想定した、ブラウザベースのCMS試作です。

- 広告利用画面①: 縦/横を選択して表示。縦は1枚表示、横は上段素材・下段素材を別々に登録して2枚上下表示
- 広告利用画面②: ①と同じ仕様で、素材・縦横設定・スライド秒数を別管理
- マーブルラウンジ: 専用枠画像を使い、10:00〜11:30 / 11:30〜14:30 / 14:30〜21:00 の時間帯ごとに表示内容を管理。各時間帯で縦1枚表示または横A3サイズ2枚上下表示を選択可能。管理画面から各時間帯の固定プレビューを確認可能。初期サンプルは現在の朝・昼・夜メニュー素材。ランチ時間帯は任意文言のアイキャッチ表示に対応。PDF複数ページは1ページずつスライド
- 商品メニュー: マーブル用ヘッダー・フッター枠で、写真、商品名、金額、説明、提供時間、表示時間帯を登録し、朝・昼/夕方で自動的に出し分け。1画面1商品で、スライド秒数を指定可能
- 広告サンプル: 縦2枚、横上段1枚、横下段1枚のサンプル画像を同梱。広告①/②/マーブルそれぞれサンプル復元・サンプル削除に対応
- 会場案内: 時間、会場、名前を登録し、時間帯ごとに表示。時間帯自動表示/終日すべて表示を切替可能。終日表示では終了済みイベントの表示/非表示を選択可能。会場名の前に館・階ラベルを表示。名前は改行入力と登録後の編集に対応。1ページ10件表示、11件以上は指定秒数でスライド。ライト/ダーク切替に対応
- 会場案内の現在対象強調: 開始30分前から開始後2時間までのブロックを強調表示
- サーバー保存版: PHP環境では管理ログイン、素材アップロード、表示データ保存、TableCheck同期、レポート表示に対応

広告素材を複数登録した場合は、管理画面で指定した秒数ごとにスライドショー表示します。
初期値は5秒です。
PDFが複数ページの場合は、1ページずつ広告素材として扱います。
PDF表示はサイネージ内で崩れにくいように、高解像度で画像化して表示します。

## 開き方

このフォルダで簡易サーバーを起動して、ブラウザで以下を開きます。

```sh
python3 -m http.server 5173
```

- 管理画面: `http://localhost:5173/`
- 広告表示①: `http://localhost:5173/index.html?screen=ad1`
- 広告表示②: `http://localhost:5173/index.html?screen=ad2`
- マーブルラウンジ: `http://localhost:5173/index.html?screen=marble`
- 商品メニュー: `http://localhost:5173/index.html?screen=menu`
- 会場案内: `http://localhost:5173/index.html?screen=venue`

## 保存について

静的環境やローカル簡易サーバーでは、登録データは同じブラウザ内に保存されます。
PHPが動く公開サーバーでは、`state.php` と `upload.php` を使ってサーバー側に保存します。

## 公開サーバー設定

GitHubには秘密情報と運用データを入れません。
公開サーバーには以下を別途配置してください。

- `auth-config.php`: 管理画面ログイン用のパスワードハッシュ
- `tablecheck-config.php`: TableCheck APIキー
- `.htpasswd-newitaya`: Basic認証用ファイル
- `data/`: 保存データと同期キャッシュ
- `uploads/`: アップロードされた広告素材・商品写真

設定ファイルは以下をコピーして作成します。

- `auth-config.example.php`
- `tablecheck-config.example.php`

## 共同作業

GitHubなどで共同作業する場合は、この `itaya_cms` フォルダだけを共有対象にします。
親フォルダ全体には制作元データが含まれるため、リポジトリには入れないでください。

- `CODEX_COLLABORATION_20260514.md`: Codex/GitHubでの共同作業方針
- `PROJECT_STATUS_20260514.md`: 現在の実装状況と次候補
- `DEPLOY_CHECKLIST_20260514.md`: テスト公開時の確認メモ
